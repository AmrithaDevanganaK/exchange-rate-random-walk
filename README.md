# Exchange Rate Modeling using Random Walks

## Mater of Science - Data Science and Analytics Dissertation Project

This repository contains my MSc dissertation project on exchange rate forecasting using stochastic and time series models in R.

## Models Used

- Discrete Random Walk
- White Noise Random Walk
- ARIMA(0,1,1)
- GARCH(1,1)

## Dataset

Source:
Federal Reserve Economic Data (FRED)

Currency Pair:
USD/GBP (DEXUSUK)
USD/EUR (DEXUSEU)

## Tools

- R
- forecast package
- rugarch
- ggplot2
